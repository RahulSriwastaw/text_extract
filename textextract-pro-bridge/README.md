# TextExtract Pro Bridge — v2.2.0

High-performance multi-AI document & MCQ digitizer bridge for TextExtract (Gemini, DeepSeek, ChatGPT, Claude). 100% Free with Zero Token limits.

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked** and select this directory
4. Keep your preferred AI chat tab open (Gemini, DeepSeek, ChatGPT, or Claude)
5. Return to TextExtract and start extracting!

## Features
- **Multi-Page Autonomous Digitization**: Sequentially digitizes documents page-by-page.
- **Zero API Quota / Zero Token Cost**: Uses your active browser session directly.
- **Multi-Model Intelligence**: Supports Gemini Web, DeepSeek Web, ChatGPT Web, and Claude Web.
- **Robust Math & Layout Support**: Guarantees LaTeX `$$...$$` formatting and structured MCQ options.
